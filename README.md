# 💰 Финансовый учёт расходов

Простое и удобное приложение для ведения личного или семейного бюджета. Позволяет записывать траты, группировать их по категориям, анализировать статистику и контролировать финансовые потоки.

## 🚀 Возможности

- Добавление расходов с указанием суммы, категории, даты и комментария.
- Редактирование и удаление записей.
- Категоризация трат (продукты, транспорт, развлечения, коммунальные услуги и т.д.).
- Фильтрация и сортировка по дате, категории, сумме.
- Просмотр общей суммы расходов за выбранный период.
- Построение простых диаграмм (круговая/столбчатая) для анализа структуры трат.
- Многопользовательский режим с авторизацией.

## 🛠 Технологии

- **Язык/Платформа:** (Python + Django, React)
- **База данных:** (PostgreSQL)
- **Фронтенд:** (HTML/CSS/JS, React)
